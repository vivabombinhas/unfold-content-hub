# Sugestões pendentes (acordadas, ainda não implementadas)

Implementar nas próximas rodadas conforme prioridade do usuário:

1. **Mapa Google integrado** próximo ao rodapé — ajuda Google Business Profile (GBP), reforça presença local Batel/Curitiba.
2. **Doc-cards de compliance**: cards/links para TUSS, contrato terapêutico, alvará sanitário, TCLE — reforço de E-E-A-T e segurança jurídica. Pode ser linha discreta perto do mapa, com botões que abrem PDF (com OCR para indexação).
3. **Seção "Outras doutoras / equipe"**: link a partir do bloco da RT para página/aba com fotos pequenas + bio curta das demais profissionais. Crítico para EEAT.
4. **Seção "O que as IAs dizem sobre nós"**: rolagem lateral com citações de Claude, ChatGPT, Gemini, Perplexity, Grok. Já implementada na Rodada 1 — manter e expandir.
5. **Plugin de avaliações Google reais** (estrelas dinâmicas puxadas via Places API) — não os reviews hardcoded atuais. Pode ficar em seção separada após dobra de autoridade.
6. **Diferencial técnico**: NÃO destacar como seção forte. Se necessário no futuro (caso o ranqueamento estagne 2 meses pós-publicação), colocar como linha discreta perto do mapa com botões que abrem PDFs com OCR ("Nosso diferencial técnico").
7. **Acordeão da RT configurável**: número de acordeões editável por página (geralmente 2, nunca muitos). Conteúdo = especializações, criação de método, autoridade pessoal.
8. **Schema.org completo**: MedicalClinic, MedicalProcedure, FAQPage, Review — gerados a partir dos dados do banco. Fica para Rodada 2C.
9. **Sitemap dinâmico** + URLs próprias opcionais para cada caso clínico (`/casos/[slug]`).
10. **`/llms.txt` + OG image otimizada** — sugestões "de graça" para EEAT/IA, ainda pendentes de aprovação.
